# 验收标准（DoD）

## 1. 单次会话通过标准

一次回放会话判定为“通过”，需同时满足：

| 指标 | 阈值 | 说明 |
|---|---|---|
| 会话完成 | 是 | 目标客户端正常结束并给出成绩 |
| 异常提示 | 0 次 | 无“数据异常 / 成绩无效 / 验证异常” |
| 里程偏差 | ≤ 2% | 客户端显示里程 vs 素材理论里程 |
| 配速偏差 | ≤ 3% | 客户端平均配速 vs 素材平均配速 |
| 步频偏差 | ≤ 5% | 客户端步频 vs 素材步频 |
| 步频区间 | 40–300 步/分 | 全程不越界 |
| 配速区间 | 2–10 分/公里 | 全程不越界 |
| 轨迹重合 | ≥ 95% | 客户端轨迹与素材轨迹的采样点重合率 |
| 人工干预 | 仅开始/结束 | 中途无手工修正 |

## 2. 阶段验收（DoD）

| 阶段 | 通过条件 |
|---|---|
| M1 录制闭环 | 素材录制完成、校验通过、字段齐全 |
| M2 回放闭环 | Mock 引擎下目标客户端能走完流程（允许标记） |
| M3 注入联调 | 正式引擎下 1 次会话通过单次标准 |
| M4 验收通过 | 连续 2–3 次会话通过单次标准，且 14 天内无人工复核驳回 |

> 单素材策略下不使用“连续 5 次”作为门槛，避免验收本身制造重复指纹。

## 3. 指标定义

- **里程偏差** = |客户端里程 − 素材里程| / 素材里程；
- **配速偏差** = |客户端平均配速 − 素材平均配速| / 素材平均配速；
- **步频偏差** = |客户端平均步频 − 素材平均步频| / 素材平均步频；
- **轨迹重合率** = 客户端轨迹点中，与素材轨迹最近点距离 ≤ 15m 的比例。

## 5. 回滚规则

出现以下任一情况，回滚到上一个通过验收的配置：

- 连续 2 次会话出现异常提示；
- 里程偏差 > 5% 且无法用接入偏移解释；
- 步频偏差 > 10%；
- 注入层版本或目标版本发生变化。

回滚后重新执行 M3 验收，通过后方可继续。
