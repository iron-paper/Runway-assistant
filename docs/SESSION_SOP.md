# 会话操作手册（SOP）

本手册规定每一次“记录 / 回放”会话的标准动作。任何偏离都要记入会话记录表。

## 1. 录制会话

### 1.1 前置检查

- [ ] 设备已 root，注入层未启用（录制阶段不注入）
- [ ] 目标客户端不在前台运行
- [ ] 电量 ≥ 50%，存储 ≥ 2GB
- [ ] 屏幕常亮已开启，省电策略已对本应用放行
- [ ] 位置服务为“高精度”，WiFi 状态与正式回放时一致

### 1.2 动作顺序

1. 站在录制起点，打开跑道助手 → 录制页；
2. 点“开始记录”，等待 60 秒前奏（静止站立，定位收敛）；
3. 点“标记跑步开始”，开始按预定路线跑；
4. 跑完目标距离后继续跑到**整圈点**（400m 跑道按整圈结束）；
5. 点“标记跑步结束”，原地静止 30 秒；
6. 点“停止记录”，导出素材并运行校验。

### 1.3 录制约束

| 项 | 要求 |
|---|---|
| 最短长度 | ≥ 3.2km（建议 5km） |
| 前奏 | 60 秒，含定位从无到有的收敛过程 |
| 结束段 | 30 秒，含减速与停步 |
| 设备 | 固定一台，固定 ROM，固定系统版本 |
| 环境 | 与回放同一场地（操场）、同一时段窗口 |
| 标记 | 跑步开始/结束必须打点 |

## 2. 回放会话

### 2.1 启动顺序（固定，不得调换）

```
① 打开跑道助手 → 回放页 → 选择素材 → 校验通过
② 点“注入就绪”（注入层开始接管，目标客户端尚未启动）
③ 打开目标客户端 → 登录 → 进入跑步页
④ 点目标客户端“开始跑步”，同时点跑道助手“开始回放”
⑤ 正片按 1:1 播放，期间保持前台亮屏
⑥ 达到目标里程后：先点跑道助手“暂停”，再点目标客户端“结束”
⑦ 目标客户端完成结算后，点跑道助手“停止并复位”
```

### 2.2 接入延迟预算

| 项 | 限制 |
|---|---|
| 从“注入就绪”到“开始回放” | ≤ 5 分钟 |
| 素材长度 | ≥ 目标里程 + 5 分钟 × 速度 |
| 超预算处理 | 复位重来，不得在中途“跳段” |

### 2.3 结束语义

- 结束前必须让注入暂停，避免结算期间位置继续变化；
- 结束后注入器停在最后位置，**不得继续播放**；
- 下一次会话前必须复位到素材起点。

### 2.4 复位

- 点“复位”后，注入器回到素材 `rel_ms = 0`；
- 确认目标客户端已退出跑步页；
- 确认手机真实定位恢复正常（关闭注入后观察一次定位）。

## 3. 使用节奏

| 项 | 建议 |
|---|---|
| 单素材使用次数 | ≤ 3 次 |
| 单日会话 | ≤ 1 次 |
| 每周会话 | 3–5 次，贴合正常作息 |
| 时段 | 固定窗口，避免深夜或异常时段 |
| 账号 | 一机一号，不切换 |

## 4. 异常处置

| 现象 | 处置 |
|---|---|
| 目标客户端提示“数据异常” | 立即停止；记录现象；连续 2 次则回滚上一配置 |
| 目标客户端提示“未在终点范围结束” | 检查结束时机与整圈点，下次调整 |
| 步频显示为 0 | 检查注入层 IMU/计步通道，重新验收 |
| 位置被拉回起点 | 检查 WiFi/基站环境，复核 K4 条件 |
| 开始被拦截（提示静止/起点） | 停止会话，复核 K1 条件与目标版本 |
| 注入中途断开 | 暂停会话，记录错误码，最多重试一次 |

## 5. 会话记录表

每次会话必须填写 `docs/ACCEPTANCE.md` 中的记录表，字段包括：素材 ID、接入偏移、开始/结束时间、目标客户端显示里程、素材里程、异常提示、结论。
