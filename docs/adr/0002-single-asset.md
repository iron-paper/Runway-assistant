# ADR-0002：单素材策略与使用次数上限

- 状态：已接受
- 日期：2026-11-19
- 决策者：项目发起人

## 背景

原始标准 S5 要求 3–5 份素材轮换，以降低跨场次指纹。实际使用中，录制成本高（每次 30 分钟以上真实跑步），发起人决定只录制一份素材、只做低频回放。

## 决策

采用单素材策略，并补两条约束：

1. 单份素材使用次数 ≤ 3 次；
2. 首次出现“数据异常/成绩无效”即停止，先补录第二份素材再继续。

验收标准相应从“连续 5 次”调整为“连续 2–3 次通过 + 14 天无人工复核驳回”。

## 后果

正面：

- 素材制作成本最低；
- 参数标定一次即可复用；
- 与目标版本锁定的策略匹配。

负面：

- 轨迹形状、步频曲线逐秒相同，重复次数越多风险越高；
- 没有备选素材，一次失败就要停；
- 接入点随机只改变起点，不改变整体指纹。

## 备选方案

- 多素材轮换：风险最低，成本最高，暂不采用；
- 参数化微扰：在物理约束内抖动轨迹与步频，需要额外的数据加工工具，列为后续路线图。
